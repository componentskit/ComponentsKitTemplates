# ComponentsKit Templates

A collection of SwiftUI templates to build iOS apps faster.

![cover](https://raw.githubusercontent.com/componentskit/ComponentsKitTemplates/HEAD/.github/cover.webp)

## Available Templates

- [Settings](https://componentskit.dev/pro#settings)
- [Paywalls](https://componentskit.dev/pro#paywalls)
- [Authentication](https://componentskit.dev/pro#auth)
- [Profiles](https://componentskit.dev/pro#profile)

## Documentation

Download the folder of the template you want to use and add its Swift files and resources to your Xcode project.

Templates are built with [ComponentsKit](https://github.com/componentskit/ComponentsKit).
